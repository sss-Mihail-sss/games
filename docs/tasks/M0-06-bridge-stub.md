# M0-06 · Заглушка bridge

## Цель

Первая настоящая игра в каталоге: 3D-сцена, по которой аватар ходит на WASD. Она проверяет всю цепочку M0: контракт, цикл, ввод, оболочку и очистку ресурсов. Физики пока нет, она появится в M1.

## Что сделать

- [ ] Пакет `games/bridge` (`@repo/game-bridge`) с раскладкой из `ARCHITECTURE.md`: `src/manifest.ts`, `src/sim/`, `src/client/`. Папки `server/` и `bots/` пока не нужны.
- [ ] `exports` только `./manifest` и `./client`. Вход `./server` добавим в M2.
- [ ] `sim/`: состояние аватара (позиция, направление взгляда) и функция `step(state, input: InputFrame, dt)`. Без Three.js и DOM: только числа, свои маленькие vec-хелперы или чистая математика.
- [ ] `client/`: Three.js-сцена — земля, два берега и провал между ними (как временная геометрия из примитивов), аватар-капсула, свет, камера, которая следует за аватаром.
- [ ] Рендер интерполирует позицию между предыдущим и текущим состоянием `sim` по `alpha` из цикла.
- [ ] Ресайз через `ResizeObserver` на контейнере, а не через `window.resize`. Учитывается `devicePixelRatio` (ограничь, например, `min(dpr, 2)`).
- [ ] Unmount освобождает всё: цикл, ввод, `ResizeObserver`, геометрии, материалы, `renderer.dispose()`, `renderer.forceContextLoss()`, удаление canvas.
- [ ] Тесты на `sim/step`: движение вперёд, движение по диагонали не быстрее, чем по прямой, нулевой ввод не двигает аватар.

## Критерии приёмки

- При 30 Гц симуляции движение на 144 Гц мониторе выглядит плавно: нет ступенек, интерполяция работает. Проверь, временно выставив `tickRate = 5`: аватар должен двигаться плавно, но с заметной задержкой.
- `sim/` не импортирует ничего из `three` и `client/`. Проверь через `grep` или правило в tsconfig.
- Все критерии очистки из M0-05 выполняются с настоящей игрой.

## Подсказки

- Направление движения считай относительно камеры, а не мира, иначе W перестанет означать «вперёд», как только камера повернётся. Но в `sim` камеры нет. Подумай, как передать её поворот: например, как часть ввода (yaw в `InputFrame`). Тогда сервер в M2 получит его так же, как клавиши.
- WebGPURenderer пока не трогаем: в M0 хватит `WebGLRenderer`. Переход обсудим в M1, когда будет понятна нагрузка.
- Арт временный. Сразу делай масштаб в метрах (капсула примерно 1.7 м), потом физика скажет спасибо.
