# @repo/ui

React-компоненты оболочки сайта: каталог, профиль, лидерборды, HUD поверх игр.

## Почему `@ui-sdk`

Компоненты строятся на `@ui-sdk/core` и `@ui-sdk/react`, потому что этот SDK позволяет создавать собственные компоненты: он даёт поведение, состояния и доступность, а внешний вид мы задаём сами. Варианты оформления описываются через `tailwind-variants` (см. `src/components/button/button.variants.ts`).

## Правила

- Приложения импортируют компоненты только из `@repo/ui`, а не из `@ui-sdk/*` напрямую. Вся зависимость от SDK остаётся внутри этого пакета.
- `react` — peer-зависимость: версию React задаёт приложение, чтобы в бандле была одна копия.

## Риски

`@ui-sdk` сейчас в бете (`0.1.0-beta.x`), и между бета-версиями API может меняться. Поэтому:

- версию лучше закрепить точно, без `^`, и обновлять осознанно;
- если SDK сломается или будет заброшен, заменить его можно внутри `@repo/ui`, не трогая приложения, — благодаря правилу выше.
